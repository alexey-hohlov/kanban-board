## Kanban Board

Kanban board with draggable elements that I developed. All data is stored in localStorage.

[Here is](https://alexey-hohlov.github.io/auth-forms/) a live demo, deployed on GitHub Pages 🌎

## 💻 Technologies
* TypeScript
* React
* Redux Toolkit
* dnd-kit
* React Hook Form
* TailwindCSS

## 🚀 Features
* Drag-and-Drop functionality
* Animated components
* Creating, editing, and deleting boards/columns/tasks
* Pin favorite boards
* All data is automatically saved to localStorage

## 🤖 How to run

```bash
yarn install
#
yarn dev
```
Go to [http://localhost:3000](http://localhost:5173) to see result
